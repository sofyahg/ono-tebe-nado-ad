# Оно тебе надо

Учебный проект: статическая страница аукциона вещей, в которые когда-то не верили.

## Как открыть

Откройте `index.html` в браузере. Сборка и установка пакетов не требуются.

## Структура

- `index.html` — семантическая разметка;
- `styles/` — глобальные и локальные стили;
- `fonts/` — локальные шрифты Raleway;
- `images/` — изображения лотов, логотипы и иконки.

Репозиторий: https://github.com/sofyahg/ono-tebe-nado-ad
